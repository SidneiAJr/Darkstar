# 🐛 Bug Reports & Issues

Found a bug? Something is broken or behaving unexpectedly? Please let us know!

---

## How to report

### Option 1 — GitHub Issues (preferred)

Open an issue at: **[github.com/your-username/darkstar/issues](https://github.com/your-username/darkstar/issues)**

Please include:

- **Description** — What happened? What did you expect to happen?
- **Steps to reproduce** — How can we reproduce the issue?
- **Environment** — Node.js version, OS, DarkStar version
- **Error output** — Paste the full error message or stack trace
- **Code snippet** — Share the relevant code if possible

---

## Issue templates

When opening a GitHub issue, use one of the labels below to help us triage faster:

| Label | When to use |
|---|---|
| `bug` | Something is broken or not working as expected |
| `crash` | The framework or CLI is crashing |
| `orm` | Issues with the query builder or model layer |
| `cli` | Issues with `darkstar forge` commands |
| `migration` | Issues with database migrations |
| `docs` | Documentation is wrong or missing |
| `question` | Not sure if it's a bug? Ask here |

---

## Before reporting

Please check:

- [ ] You are on the latest version of DarkStar
- [ ] The issue hasn't already been reported in [open issues](https://github.com/your-username/darkstar/issues)
- [ ] You've read the README and the issue isn't a configuration mistake

---

> 🪐 DarkStar is in alpha — bugs are expected. Every report helps make it better. Thank you!
